## 零、声明方式与 API

```js
const re1 = /\d+/g                      // 字面量，编译期确定，性能更好
const re2 = new RegExp('\\d+', 'g')     // 构造函数，可拼接变量（注意反斜杠要双写）
const re3 = new RegExp(`^${key}=`, 'g') // 变量来自用户输入时记得转义元字符
```

| 正则匹配          | 语法                                    |
|-------------------|-----------------------------------------|
| regex.test(str)   | 返回Boolean值                           |
| str.match(regex)  | 无 `g` 返回 exec 同款数组；有 `g` 返回所有匹配内容组成的数组 |
| str.matchAll(regex)  | 返回迭代器，每项含捕获组（必须带 `g`，ES2020） |
| regex.exec(str)   | 返回数组  [匹配内容，index, input, group] |
| str.search(regex) | 返回第一次匹配regex的位置               |
| str.split(regex)  | 返回按regex分割的数组                   |
| str.replace(regex, callback)  | 对匹配的内容进行callback替换                 |
| str.replaceAll(regex, x)  | 替换全部，正则必须带 `g`（ES2021）      |

正则实例上的属性：`source`（模式文本）、`flags`、`lastIndex`（`g`/`y` 下次匹配的起点）、`global`/`ignoreCase`/`multiline` 等。

```js
const str = "https://www.google.com.hk/search?q=%E6%89%93%E5%8F%91%E6%96%AF%E8%92%82%E8%8A%AC&oq=%E6%89%93%E5%8F%91%E6%96%AF%E8%92%82%E8%8A%AC&aqs=chrome..69i57.1222j1j7&sourceid=chrome&ie=UTF-8"

const regex = /=/g

const resultTest = regex.test(str)  // true

const resultMatch = str.match(regex)  // ['=','=','=','=','=']


```


## 一、字符类（匹配"一个"字符）

| 语法 | 描述 | 等价写法 |
|------|------|----------|
| `.` | 除换行符外的任意字符（加 `s` 标志后包括换行） | `[^\n\r\u2028\u2029]` |
| `\w` | 单词字符：字母、数字、下划线 | `[A-Za-z0-9_]` |
| `\W` | 非单词字符 | `[^A-Za-z0-9_]` |
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\s` | 任意空白：空格、制表、换页、换行等 | `[ \f\n\r\t\v\u00a0\ufeff…]` |
| `\S` | 非空白 | — |
| `[abc]` | 字符集合，匹配其中任意一个 | — |
| `[^abc]` | 取反集合，匹配除此之外的字符 | — |
| `[a-z0-9]` | 范围集合，多个范围可并列 | — |
| `\uXXXX` | Unicode 码点（`u` 标志下可用 `\u{1F600}`） | 汉字区间 `[\u4e00-\u9fa5]` |
| `\xXX` | 两位十六进制字符，如 `\x41` → `A` | — |
| `\n \r \t \v \f \0` | 换行、回车、制表、垂直制表、换页、NUL | — |
| `\p{...}` | Unicode 属性（需 `u` 标志），如 `\p{Script=Han}` | ES2018 |
| `\P{...}` | Unicode 属性取反 | ES2018 |

需要转义的元字符：`^ $ . * + ? ( ) [ ] { } | \ /`。在字符集 `[]` 内部只需转义 `] \ ^ -`。

## 二、量词（控制"重复几次"）

| 语法 | 描述 |
|------|------|
| `*` | 0 次或多次，等价 `{0,}` |
| `+` | 1 次或多次，等价 `{1,}` |
| `?` | 0 次或 1 次，等价 `{0,1}` |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |

量词默认**贪婪**（尽可能多匹配），后面加 `?` 变**懒惰**（尽可能少），加 `+` 变**独占**（匹配后不回溯，JS 不支持）。

```js
const html = '<p>a</p><p>b</p>'
html.match(/<p>.*<\/p>/)[0]   // '<p>a</p><p>b</p>'  贪婪
html.match(/<p>.*?<\/p>/)[0]  // '<p>a</p>'          懒惰
```

## 三、锚点与边界（匹配"位置"，不消耗字符）

| 语法 | 描述 |
|------|------|
| `^` | 字符串开头；加 `m` 标志后是每行开头 |
| `$` | 字符串结尾；加 `m` 标志后是每行结尾 |
| `\b` | 单词边界（`\w` 与 `\W` 的交界处） |
| `\B` | 非单词边界 |
| `\A` `\z` `\Z` | 字符串绝对首/尾（JS 不支持，Java/PHP 等支持） |

```js
'hello world'.replace(/\b\w/g, c => c.toUpperCase())  // 'Hello World'
```

## 四、分组与引用

| 语法 | 描述 |
|------|------|
| `(x)` | 捕获组，按左括号顺序编号 `$1 $2 …` |
| `(?:x)` | 非捕获组，只分组不编号，性能更好 |
| `(?<name>x)` | 命名捕获组（ES2018），通过 `groups.name` 取值 |
| `\1` `\2` | 反向引用，匹配第 n 个捕获组**已捕获到的内容** |
| `\k<name>` | 命名反向引用 |
| `x|y` | 择一分支，优先匹配左边；用 `(?:x|y)` 限定范围 |

```js
// 反向引用：找出连续重复的字符
'aabbcd'.match(/(\w)\1/g)          // ['aa', 'bb']

// 命名捕获组
const m = '2017-05-11'.match(/(?<y>\d{4})-(?<m>\d{2})-(?<d>\d{2})/)
m.groups.y  // '2017'
'2017-05-11'.replace(/(?<y>\d{4})-(?<m>\d{2})-(?<d>\d{2})/, '$<d>/$<m>/$<y>')  // '11/05/2017'
```

## 五、断言（零宽，只做条件判断）

| 语法 | 名称 | 描述 |
|------|------|------|
| `(?=x)` | 正向先行 | 后面**必须是** x |
| `(?!x)` | 负向先行 | 后面**不能是** x |
| `(?<=x)` | 正向后行 | 前面**必须是** x（ES2018） |
| `(?<!x)` | 负向后行 | 前面**不能是** x（ES2018） |

```js
'￥100 $200'.match(/(?<=\$)\d+/)[0]   // '200'  取美元金额
'100px 200em'.match(/\d+(?=px)/)[0]   // '100'  取 px 数值
/^(?!.*\s)(?=.*\d).{6,}$/.test('abc123')  // 不含空白且含数字，至少 6 位
```

## 六、标志（flags）

| 标志 | 全称 | 描述 |
|------|------|------|
| `g` | global | 全局匹配，不在第一个结果处停止 |
| `i` | ignoreCase | 忽略大小写 |
| `m` | multiline | 多行模式，`^ $` 匹配每行首尾 |
| `s` | dotAll | 让 `.` 也能匹配换行符（ES2018） |
| `u` | unicode | 按码点匹配，支持 `\p{...}` 与 `\u{...}`，正确处理 emoji |
| `y` | sticky | 粘连模式，必须从 `lastIndex` 处开始匹配 |
| `d` | hasIndices | 结果附带每个捕获组的 `indices`（ES2022） |

`g` 和 `y` 会让 `RegExp` 实例保持 `lastIndex` 状态，因此**不要复用同一个带 `g` 的正则做多次 `test`**：

```js
const re = /a/g
re.test('a')  // true，lastIndex 变成 1
re.test('a')  // false ← 陷阱
```

## 七、replace 中的替换字符串

| 语法 | 描述 |
|------|------|
| `$&` | 匹配到的整个子串 |
| `` $` `` | 匹配位置之前的内容 |
| `$'` | 匹配位置之后的内容 |
| `$n` | 第 n 个捕获组 |
| `$<name>` | 命名捕获组 |
| `$$` | 字面量 `$` |

回调形式：`replace(re, (match, p1, p2, …, offset, string, groups) => …)`。

### **实现千位分隔符**

``` js
function format(number) {
    // (?=(\d{3})+$) 断言：后面剩余的数字个数正好是 3 的倍数
    var regx = /\d{1,3}(?=(\d{3})+$)/g;
    return (number + '').replace(regx, '$&,');  // $& 表示与 regx 相匹配的字符串
}

format(1234567)  // '1,234,567'
```

### **获取url中参数**

1. 指定参数名称，返回该参数的值 或者 空字符串
2. 不指定参数名称，返回全部的参数对象 或者 {}
3. 如果存在多个同名参数，则返回数组

``` js
function getUrlParam(url, key) {
    var arr = {};
    url.replace(/\??(\w+)=(\w+)&?/g, function(match, matchKey, matchValue) {
        if (!arr[matchKey]) {
            arr[matchKey] = matchValue;
        } else {
            var temp = arr[matchKey];
            arr[matchKey] = [].concat(temp, matchValue);
        }
    });
    if (!key) {
        return arr;
    } else {
        for (var ele in arr) {
            if (ele === key) {   // 注意是 ===，写成 = 会变成赋值
                return arr[ele];
            }
        }
        return '';
    }
}
```

## 九、常见陷阱

1. **带 `g` 的正则有状态**。`lastIndex` 会累积，导致第二次 `test`/`exec` 结果异常。要么每次新建正则，要么手动 `re.lastIndex = 0`。
2. **`match` 有无 `g` 返回结构不同**。无 `g` 返回带 `index`/捕获组的数组，有 `g` 只返回匹配到的字符串数组、丢掉捕获组。要同时拿全部匹配和捕获组，用 `matchAll`。
3. **`new RegExp` 里反斜杠要双写**。`new RegExp('\\d+')` 才等于 `/\d+/`。拼接用户输入前先转义元字符：`s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`。
4. **灾难性回溯**。嵌套量词如 `/(a+)+$/` 遇到长串不匹配时复杂度指数级上升，可造成 ReDoS。避免 `(x+)+`、`(x*)*`、`(x|y)*` 这类可产生多种同解路径的写法，优先用非捕获组 + 明确的字符类。
5. **`.` 默认不匹配换行**。跨行匹配用 `s` 标志，或退化写法 `[\s\S]`。
6. **`^ $` 默认针对整个字符串**，逐行处理要加 `m`。
7. **emoji 与代理对**。不带 `u` 时 `/./` 只匹配半个字符，`'😀'.length === 2`。处理 Unicode 一律加 `u`。
8. **字符集里的 `-` 位置敏感**。`[a-z]` 是范围，`[-az]`/`[az-]`/`[a\-z]` 才是字面量减号。
